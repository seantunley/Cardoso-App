## Codebase Patterns
- server.js uses ESM (import/export) — all new src/ files must also use import/export (package.json has "type": "module")
- `createRequire(import.meta.url)` is used for JSON imports (e.g., package.json)
- db singleton: src/db/index.js exports the db instance. All modules import from there — never open new Database()
- HUB_MODE routes: wrap in if (process.env.HUB_MODE === 'true') checks
- Versioned migrations: src/db/migrations.js exports buildMigrations(db) and runMigrations(db)
- Schema init: src/db/schema.js exports initSchema(db) — PRAGMAs, CREATE TABLEs, indexes, custom field config, migrations
- Prepared statements: src/db/statements.js exports buildStatements(db)
- server.js had pre-existing merge corruption from commit 47c41c5 — restored from 4a0e196 (last valid commit)
- Auth middleware: createAuthMiddleware({ getUserById, sanitizeUser }) factory pattern — dependencies injected from server.js
- Rate limiter: standalone export from src/middleware/rateLimit.js
- Field registry: src/fieldRegistry.js exports FIELD_REGISTRY, INVOICE_SLOTS, RECEIPT_SLOTS, buildFieldPatch, buildDynamicLocalFieldsPatch, and mapping helpers
- Shared helpers: src/helpers.js exports sanitizeForSqlite, parseJsonSafely, stringifyJsonSafely, expandDataRecord, normalizeFieldKey, validateCustomFieldKey, boolFromRow, defaultPermissionsForRole, sanitizeUser, sanitizeConnection
- fieldRegistry.js imports parseJsonSafely from helpers.js — no circular deps since neither imports from routes/services
- Auto-flag service: src/services/autoFlag.js exports _evalCondition, _evalRuleConditions, applyAutoFlagRulesToRecord — pure functions, no deps
- Auth router: createAuthRouter({ db, stmts, getUserById, requireAuth, requireAdmin, requireSelfOrAdmin, loginLimiter }) factory pattern
- Route files use express.Router() and full paths (e.g., '/api/auth/login'), mounted with app.use(router)
